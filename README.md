# OOPProjekts - Dārgumu Medības Džungļos

## Apraksts

"Dārgumu Medības Džungļos" ir izglītojoša spēle, kas izstrādāta Python programmēšanas valodā, izmantojot Pygame bibliotēku. Spēlētājam jāievada savs vārds, jāizvēlas kategorija un grūtības līmenis, pēc tam jāatbild uz 10 jautājumiem. Par pareizām atbildēm tiek piešķirti punkti, bet par nepareizām – atņemti punkti. Spēles beigās tiek parādīts rezultāts un tas tiek saglabāts CSV failā.

## Izmantotās tehnoloģijas

* Python 3.12
* Pygame
* JSON
* CSV

## Projekta palaišana no Python koda

Projektu ieteicams palaist ar Python 3.12 versiju, jo Pygame bibliotēka pilnībā atbalsta šo versiju.

Nepieciešamās bibliotēkas instalēšana: pip install pygame

Programmas palaišana: python saskarne_main.py


## Projekta palaišana bez Python instalēšanas

Projektam ir pievienots izpildāmais fails DargumuMedibas.exe, kas atrodas mapē dist/.

To iespējams palaist bez Python un Pygame instalēšanas.

Lai spēle darbotos korekti, .exe failam jāatrodas kopā ar mapēm:assets, dati
